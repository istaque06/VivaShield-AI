# VivaShield AI

VivaShield AI is an AI-powered emergency safety assistant designed to provide calm, clear, and practical first-response safety guidance during emergency situations.

## Features

- AI-powered emergency safety guidance
- Medical emergency guidance
- Fire emergency guidance
- Accident safety guidance
- Personal safety guidance
- Simple and user-friendly interface
- Real-time AI responses using Google Gemini API
- Secure API key handling using environment variables
- Responsive web interface

## Emergency Categories

VivaShield AI currently supports:

- Medical Emergency
- Fire Emergency
- Accident
- Personal Safety
- General Emergency
